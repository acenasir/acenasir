## LOGO & BRAND ELEMENTS

### Logo Design
```
TEXT LOGO:
Prompt[Pro]

- "Prompt" in White (#FFFFFF)
- "Pro" in Emerald (#10B981)
- Font: Poppins Bold
- Optional: Bracket styling around "Pro"

ICON VERSIONS:
1. "PP" monogram in emerald
2. Command prompt cursor (▌) in emerald
3. Sparkle/AI symbol + "P"
```

### Repeating Pattern (for backgrounds)
```
Create a subtle pattern using:
- Small dots in #10B981 at 10% opacity
- Grid lines at 5% opacity
- Or diagonal lines at 5% opacity

Use as overlay on solid color backgrounds
```

## CANVA QUICK START

1. **Go to Canva.com** → Create Design
2. **Select size:**
   - Twitter: 1200 x 675 px
   - Instagram Post: 1080 x 1080 px
   - Instagram Story: 1080 x 1920 px
3. **Set brand colors:**
   - Background: #1E293B
   - Primary: #10B981
   - Text: #FFFFFF
4. **Add fonts:**
   - Poppins (headlines)
   - Inter (body)
5. **Follow templates above**

---

## BATCH CREATION TIPS

1. **Create a Brand Kit** in Canva with your colors and fonts
2. **Make one master template** for each format
3. **Duplicate and modify** for each post
4. **Use Canva's "Resize"** to adapt between platforms
5. **Export as PNG** for best quality
