# Home Services AI Prompt Pack
## 50+ Ready-to-Use Prompts for Plumbers, Electricians, HVAC, Contractors & Handymen

---

## QUOTES & ESTIMATES (10 Prompts)

### 1. Initial Quote Email
```
Write a professional quote email for [SERVICE: e.g., water heater replacement, electrical panel upgrade, AC installation]. Client: [NAME]. Address: [ADDRESS]. Scope of work: [DESCRIBE]. Quote: $[AMOUNT]. Include: what's included, materials, labor, warranty, timeline, and payment terms. Valid for [X] days.
```

### 2. Detailed Estimate Breakdown
```
Create a detailed estimate breakdown for [PROJECT]. Client: [NAME]. Line items needed: [LIST - labor, materials, permits, disposal, etc.]. Total: $[AMOUNT]. Format it clearly with itemized costs. Include notes on what could affect final price. Professional and transparent.
```

### 3. Quote Follow-Up
```
Write a follow-up email to [CLIENT NAME] who received a quote [X] days ago for [SERVICE] but hasn't responded. Be helpful, not pushy. Offer to answer questions, mention quote expiration if applicable, and leave door open. Keep it brief.
```

### 4. Competitive Price Response
```
Write a response to a client who says my quote ($[MY AMOUNT]) is higher than another contractor's ($[THEIR AMOUNT]). Explain value differences (licensing, insurance, warranty, quality materials, reviews). Don't bash competitors. Help them make an informed decision.
```

### 5. Change Order Request
```
Write a change order document for additional work discovered during [ORIGINAL PROJECT]. Additional work needed: [DESCRIBE]. Additional cost: $[AMOUNT]. Additional time: [X] days. Explain why it's necessary and get client approval before proceeding. Professional format.
```

### 6. Emergency Service Quote
```
Write a quote for emergency service provided to [CLIENT NAME] at [ADDRESS]. Issue: [DESCRIBE]. Service provided: [WHAT YOU DID]. Parts used: [LIST]. Emergency rate: $[AMOUNT]. Regular follow-up work recommended: [IF APPLICABLE]. Clear and fair.
```

### 7. Maintenance Agreement Proposal
```
Write a proposal for an annual maintenance agreement to [CLIENT NAME]. Services included: [LIST - e.g., bi-annual HVAC tune-ups, priority scheduling, discount on repairs]. Annual cost: $[AMOUNT] or $[MONTHLY]/month. Benefits: longer equipment life, fewer emergencies, peace of mind.
```

### 8. Quote Comparison Chart
```
Create a quote comparison explanation for [CLIENT NAME] showing [GOOD/BETTER/BEST] options for [PROJECT]. Option 1: [BASIC - describe and price]. Option 2: [STANDARD - describe and price]. Option 3: [PREMIUM - describe and price]. Explain trade-offs clearly.
```

### 9. Commercial/Large Project Quote
```
Write a formal quote for a commercial project at [BUSINESS NAME]. Project: [DESCRIBE]. Scope: [DETAILED SCOPE]. Timeline: [START] to [END]. Payment schedule: [TERMS]. Include: insurance info, licensing, and terms and conditions. More formal tone.
```

### 10. Warranty Quote for Return Issue
```
Write a response to [CLIENT NAME] reporting an issue with work I completed [X] months ago. Issue: [DESCRIBE]. My assessment: [COVERED UNDER WARRANTY / NOT COVERED AND WHY]. Next steps: [WHAT I'LL DO]. Professional and fair.
```

## CLIENT COMMUNICATION (12 Prompts)

### 11. Appointment Confirmation
```
Write an appointment confirmation for [CLIENT NAME]. Service: [TYPE]. Date: [DATE]. Arrival window: [TIME RANGE]. Address: [ADDRESS]. Include: what to expect, how to prepare (clear access, pets secured, etc.), and my contact info if they need to reach me. Friendly and professional.
```

### 12. On-My-Way Message
```
Write a brief "on my way" message to [CLIENT NAME]. Estimated arrival: [TIME]. Include: my vehicle description (if helpful), reminder to have access available, and that I'll text when I arrive. Quick and professional. Under 50 words.
```

### 13. Running Late Notification
```
Write an apology message for running late to [CLIENT NAME]'s appointment. Original time: [TIME]. New ETA: [TIME]. Reason: [BRIEF - previous job took longer]. Apologize, give updated time, offer to reschedule if the new time doesn't work.
```

### 14. Job Completion Summary
```
Write a job completion email to [CLIENT NAME]. Work completed: [DESCRIBE]. Any follow-up needed: [YES/NO - details]. Warranty information: [TERMS]. Invoice attached: $[AMOUNT]. Payment due: [TERMS]. Thank them for their business.
```

### 15. Follow-Up After Service
```
Write a follow-up message to [CLIENT NAME] [X] days after completing [SERVICE]. Check if everything is working well, answer any questions, and request a review (with link). Make it genuine, not just a review grab.
```

### 16. Diagnostic Report
```
Write a diagnostic report for [CLIENT NAME] after assessing [ISSUE]. Findings: [WHAT I FOUND]. Root cause: [EXPLAIN IN PLAIN ENGLISH]. Recommended repair: [SOLUTION]. Estimated cost: $[RANGE]. Alternative options: [IF ANY]. Help them understand what's happening.
```

### 17. Repair vs. Replace Recommendation
```
Write a recommendation to [CLIENT NAME] about whether to repair or replace their [EQUIPMENT - e.g., water heater, AC unit, furnace]. Age: [X] years. Issue: [DESCRIBE]. Repair cost: $[AMOUNT]. Replacement cost: $[AMOUNT]. Factor in: efficiency, future repairs, lifespan. Honest advice.
```

### 18. Permit Explanation
```
Write an explanation for [CLIENT NAME] about why a permit is required for [PROJECT]. Include: what the permit covers, permit cost: $[AMOUNT], timeline impact, inspection process, and why it protects them (insurance, resale, safety). Make it understandable.
```

### 19. Bad News Delivery
```
Write a message delivering bad news to [CLIENT NAME]. Issue: [DESCRIBE - e.g., repair is more extensive than expected, part is unavailable, project will cost more]. Be direct but empathetic. Present options and next steps. Don't over-apologize but acknowledge the inconvenience.
```

### 20. Job Postponement
```
Write a message to [CLIENT NAME] about postponing their scheduled work. Original date: [DATE]. New date: [DATE]. Reason: [WEATHER/MATERIALS DELAYED/EMERGENCY]. Apologize for inconvenience, confirm the new date works, offer flexibility.
```

### 21. Annual Service Reminder
```
Write an annual service reminder to past client [NAME]. Last service: [SERVICE] on [DATE]. Time for: [RECOMMENDED MAINTENANCE]. Benefits of regular maintenance: [LIST]. Include easy booking CTA and seasonal urgency if applicable (e.g., "before summer heat").
```

### 22. Final Walkthrough/Handoff
```
Write talking points for a final walkthrough with [CLIENT NAME] after completing [PROJECT]. Cover: what was done, how to operate new equipment, maintenance recommendations, warranty registration, and when to call if issues arise. Leave them confident and informed.
```

## REVIEWS & REFERRALS (8 Prompts)

### 23. Review Request
```
Write a review request to [CLIENT NAME] after completing [SERVICE]. Make it easy: include direct link to [GOOGLE/YELP/NEXTDOOR]. Mention what to include (the service, experience, results). Brief and genuine. Not pushy.
```

### 24. Google Review Response (Positive)
```
Write a response to this positive Google review: "[REVIEW TEXT]". Thank them specifically, reference the work done, and express hope to help them again. Professional but personable.
```

### 25. Google Review Response (Negative)
```
Write a professional response to this negative review: "[REVIEW TEXT]". Acknowledge their frustration, apologize if appropriate, offer to make it right, and take it offline (provide phone number). Don't be defensive. Future clients are watching.
```

### 26. Referral Request
```
Write a referral request to satisfied client [NAME]. Mention the work I did for them, explain that referrals are how I grow my business, and what's in it for them: [REFERRAL INCENTIVE if applicable]. Make it a natural ask, not desperate.
```

### 27. Referral Thank You
```
Write a thank you message to [CLIENT NAME] who referred [NEW CLIENT NAME] to me. Express genuine gratitude. Mention the referral reward if applicable: [INCENTIVE]. Reinforce that I'll take great care of their referral.
```

### 28. Nextdoor Recommendation Response
```
Write a response to a Nextdoor recommendation request where someone asked for a [SERVICE TYPE] recommendation and a client tagged me. Thank the client who recommended me, briefly introduce my services, and how to reach me. Not too salesy for the community vibe.
```

### 29. Testimonial Request
```
Write a request to [CLIENT NAME] for a testimonial I can use on my website/truck/marketing. After I completed: [PROJECT]. Guide them: ask about the problem they had, the solution I provided, and the result. Offer to draft something for their approval.
```

### 30. Year-in-Review Thank You
```
Write an end-of-year thank you to my client list. Include: gratitude for their business, a stat or two (jobs completed, families served), holiday hours, and well wishes. Genuine and warm.
```

## MARKETING & SOCIAL MEDIA (10 Prompts)

### 31. Before/After Project Post
```
Write a social media post for a before/after of [PROJECT - e.g., bathroom renovation, electrical panel upgrade, HVAC installation]. Describe the problem, the solution, and the result. Include: city/neighborhood (for local SEO), service call CTA, and relevant hashtags.
```

### 32. Educational Post (Tips)
```
Write an educational social post with tips for homeowners about [TOPIC: e.g., "Signs your water heater is failing," "How to prevent frozen pipes," "When to call an electrician vs. DIY"]. Provide value, establish expertise, include soft CTA.
```

### 33. Seasonal Reminder Post
```
Write a seasonal reminder post for [SEASON]. Topic: [e.g., "Schedule your AC tune-up before summer," "Winter-proof your plumbing," "Spring electrical safety check"]. Include: why it matters, simple homeowner tips, and CTA to schedule service.
```

### 34. Emergency Service Post
```
Write a post reminding followers I offer emergency [PLUMBING/ELECTRICAL/HVAC] services. Include: 24/7 availability, phone number, common emergencies I handle, and why to call a pro vs. wait. Reassuring tone.
```

### 35. New Service/Equipment Announcement
```
Write a post announcing I now offer [NEW SERVICE] or am certified in [NEW EQUIPMENT/TECHNOLOGY]. Explain: what it is, benefits to customers, why I added it. Establish that I'm growing and staying current.
```

### 36. "Why Hire a Licensed Pro" Post
```
Write a post explaining why customers should hire a licensed, insured [TRADE] instead of going with the cheapest option. Include: permit knowledge, warranty, liability, code compliance, and peace of mind. Informative, not preachy.
```

### 37. Meet the Team/About Me Post
```
Write an "about me" or "meet the team" post for social media. Include: years in business, licenses/certifications, family/personal touch, service area, and what sets us apart. Build trust and connection with the community.
```

### 38. Customer Story Feature
```
Write a post featuring [CLIENT NAME]'s project (with permission). The problem: [ISSUE]. The solution: [WHAT I DID]. The result: [HAPPY ENDING]. Add a client quote if available. Shows real-world value.
```

### 39. Community Involvement Post
```
Write a post about my involvement in [COMMUNITY ACTIVITY: charity, sponsorship, local event]. What I did: [DESCRIBE]. Why it matters to me: [EXPLAIN]. Humanize the business without being braggy.
```

### 40. Google Business Profile Post
```
Write a Google Business Profile post about [TOPIC: current promotion, seasonal service, new offering]. Keep it under 300 characters. Include: what's offered, benefit to customer, and CTA. Optimized for local search.
```

## BUSINESS OPERATIONS (5 Prompts)

### 41. Invoice Template
```
Create an invoice template for [COMPANY NAME]. Include: company info (address, phone, license #), client info, invoice #, date, itemized services with descriptions, materials with costs, labor, subtotal, tax if applicable, total, payment terms, and payment methods accepted.
```

### 42. Service Agreement/Contract
```
Draft a service agreement for [PROJECT TYPE]. Include: scope of work, materials to be used, timeline, payment schedule, change order process, warranty terms, and cancellation policy. Keep it clear and fair. Note: have a lawyer review before use.
```

### 43. Technician Job Posting
```
Write a job posting for a [POSITION: plumber, electrician, HVAC tech, apprentice]. Company: [NAME]. What we offer: [PAY, BENEFITS]. Requirements: [EXPERIENCE, CERTIFICATIONS]. What we're looking for: [QUALITIES]. Why work with us: [CULTURE/BENEFITS]. How to apply.
```

### 44. Supplier Negotiation Email
```
Write an email to [SUPPLIER] negotiating better pricing or terms. Current relationship: [DESCRIBE]. Volume: [MONTHLY/ANNUAL PURCHASES]. Request: [DISCOUNT/BETTER TERMS]. Frame it as a partnership discussion, not a demand.
```

### 45. Insurance/Bonding Info for Clients
```
Write a response for when clients ask about my insurance and bonding. Include: that I'm fully licensed, insured (liability and workers comp), bonded, and what this means for their protection. Offer to provide certificates if needed. Builds confidence.
```

## LOCAL SEO & MARKETING (5 Prompts)

### 46. Service Area Page Content
```
Write website content for my [SERVICE] page targeting [CITY/NEIGHBORHOOD]. Include: services offered in this area, common issues in this area (if relevant), response time, local testimonial placeholder, and call-to-action. Optimize for "[SERVICE] in [CITY]" searches.
```

### 47. FAQ Page Content
```
Write FAQ content for my website. Answer: service area, emergency availability, payment options, license/insurance info, estimate process, timeline expectations, warranty, and how to prepare for service visits. Clear and helpful.
```

### 48. Nextdoor Business Post
```
Write an introductory post for my business on Nextdoor. Introduce: who I am, services offered, neighborhoods served, and a soft offer (free estimate, discount for neighbors). Community-friendly tone, not too salesy.
```

### 49. Vehicle Wrap Copy
```
Write short, punchy copy for my service vehicle wrap. Include: company name, main services (brief), phone number, website, tagline. Must be readable at a glance. Under 20 words total for the main text.
```

### 50. Door Hanger/Flyer Copy
```
Write copy for a door hanger/flyer. Service: [TYPE]. Offer: [IF ANY - e.g., $25 off first service]. Include: services list, phone, website, license #, and compelling headline. Format for easy scanning. Local focus.
```
