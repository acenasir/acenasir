# Fitness Trainer AI Prompt Pack
## 50+ Ready-to-Use Prompts for Personal Trainers & Fitness Coaches

---

## WORKOUT PROGRAMMING (12 Prompts)

### 1. Custom Workout Plan
```
Create a [X]-week workout plan for a [GENDER], [AGE] years old, with [EXPERIENCE LEVEL: beginner/intermediate/advanced] fitness experience. Goal: [WEIGHT LOSS/MUSCLE GAIN/STRENGTH/ENDURANCE]. Available equipment: [LIST]. Available days: [X] days per week, [X] minutes per session. Include warm-up and cool-down.
```

### 2. Home Workout (No Equipment)
```
Design a full-body home workout requiring no equipment for a [BEGINNER/INTERMEDIATE] client. Duration: [X] minutes. Focus on: [GOALS]. Include: exercise name, sets, reps, rest periods, and modifications for easier/harder versions. Format as a clear, printable routine.
```

### 3. Gym Strength Program
```
Create a [X]-day strength training split for [GOAL: hypertrophy/strength/powerlifting]. Experience level: [LEVEL]. Include: compound movements, accessory work, sets/reps/RPE, progressive overload strategy. Week 1 baseline with notes on weekly progression.
```

### 4. HIIT Workout
```
Design a [X]-minute HIIT workout for [FAT LOSS/CONDITIONING]. Format: [TABATA/EMOM/AMRAP]. Equipment available: [LIST]. Include: exercise list with descriptions, work/rest intervals, total rounds, and modifications. Add a 3-min warm-up and 2-min cool-down.
```

### 5. Active Recovery Day
```
Create an active recovery routine for a client who trains [X] days per week at high intensity. Duration: 30 minutes. Include: light mobility work, foam rolling sequence, gentle stretching, and optional low-intensity cardio. Explain the purpose of each section.
```

### 6. Sport-Specific Training
```
Design a [X]-week training program for a [SPORT] athlete. Season phase: [OFF-SEASON/PRE-SEASON/IN-SEASON]. Focus areas: [SPEED/POWER/AGILITY/ENDURANCE]. Include: gym work, sport-specific drills, and recovery protocols. Consider injury prevention.
```

### 7. Senior Fitness Program
```
Create a safe, effective [X]-week program for a [AGE] year old client. Health considerations: [LIST ANY]. Goals: [MAINTAIN MOBILITY/BUILD STRENGTH/IMPROVE BALANCE]. Include: chair-assisted options, balance work, and clear safety notes. 3 days per week, 30-40 minutes.
```

### 8. Post-Rehab Return to Exercise
```
Design a gradual return-to-exercise program for a client recovering from [INJURY/SURGERY]. Cleared by doctor for [RESTRICTIONS]. Goal: rebuild strength in [AREA] while maintaining overall fitness. Weeks 1-4 progression. Include warning signs to stop.
```

### 9. Bodyweight Progression Program
```
Create a 12-week bodyweight progression program to achieve [GOAL: first pull-up/push-up/pistol squat/muscle-up]. Current level: [DESCRIBE]. Include: weekly progressions, regression exercises, accessory work, and testing protocol.
```

### 10. Quick Express Workouts
```
Create 5 different [X]-minute express workouts for busy clients. Each should be complete (warm-up to cool-down), require [MINIMAL/NO] equipment, and target different focuses: upper body, lower body, core, cardio, and full-body. Format for easy phone viewing.
```

### 11. Deload Week Program
```
Create a deload week program for a client who has been training [DESCRIBE CURRENT PROGRAM] for [X] weeks. Reduce volume by 40-50% while maintaining movement patterns. Explain to the client why deloads matter for long-term progress.
```

### 12. Travel Workout Pack
```
Create 5 hotel room workouts for a client traveling for [X] days. No equipment, minimal space, low noise (no jumping). Each workout: 20-30 minutes. Include: 2 strength, 2 cardio-focused, 1 mobility/stretch. Format as a printable PDF-style guide.
```

## NUTRITION GUIDANCE (10 Prompts)

### 13. Macro Calculation & Explanation
```
Calculate macros for a [GENDER], [AGE] years old, [HEIGHT], [WEIGHT], activity level: [SEDENTARY/LIGHTLY ACTIVE/ACTIVE/VERY ACTIVE]. Goal: [FAT LOSS/MAINTENANCE/MUSCLE GAIN]. Explain the numbers in simple terms. Include protein timing recommendations and hydration goals.
```

### 14. Sample Meal Plan
```
Create a [X]-day sample meal plan for a client with these macros: [CALORIES] calories, [P]g protein, [C]g carbs, [F]g fat. Dietary preferences: [NONE/VEGETARIAN/VEGAN/GLUTEN-FREE/DAIRY-FREE]. Include: breakfast, lunch, dinner, and [X] snacks. Simple, realistic recipes.
```

### 15. Meal Prep Guide
```
Create a weekly meal prep guide for a busy [PROFESSIONAL/PARENT/STUDENT] with [X] hours on Sunday to prep. Macros: approximately [CALORIES] calories/day. Include: shopping list, prep order, storage instructions, and how to mix-and-match components throughout the week.
```

### 16. Pre/Post Workout Nutrition
```
Explain optimal pre and post-workout nutrition for a client who trains at [TIME OF DAY] for [GOAL]. Include: timing, macro ratios, specific food examples, and what to avoid. Keep it simple and actionable. Address if they should train fasted.
```

### 17. Supplement Recommendations
```
Provide evidence-based supplement recommendations for a [GOAL: muscle gain/fat loss/performance/general health] client. Explain: what's actually worth taking, proper dosing, timing, and what's a waste of money. Cite general research consensus. Include disclaimer about consulting doctor.
```

### 18. Eating Out Guide
```
Create a guide for my client on how to eat out while staying on track with their [FAT LOSS/MUSCLE GAIN] goals. Include: how to estimate portions, best choices at common restaurants ([LIST TYPES]), what to ask for, and how to handle social pressure. Make it practical, not restrictive.
```

### 19. Habit-Based Nutrition Coaching
```
Create a 4-week habit-based nutrition plan for a client overwhelmed by macro tracking. Week 1-4 progression: one new habit per week. Focus on: [PROTEIN/VEGETABLES/WATER/PORTION CONTROL]. Include daily check-in questions and mindset tips.
```

### 20. Breaking a Plateau
```
My client has been stuck at [WEIGHT] for [X] weeks despite following their plan. Current intake: [CALORIES]. Training: [DESCRIBE]. Create a strategy to break the plateau. Include: metabolic adaptation explanation, potential solutions (refeed, diet break, calorie adjustment), and timeline.
```

### 21. Client Nutrition Check-In Questions
```
Create a weekly nutrition check-in questionnaire for my clients. Include questions about: adherence, energy levels, hunger, cravings, sleep, digestion, challenges faced, and wins. Format as a simple form they can fill out in 3 minutes.
```

### 22. Calorie Cycling Explanation
```
Explain calorie/carb cycling to my client who is interested in this approach. Include: what it is, who it's good for, a sample weekly setup for their [GOAL] with [X] training days, and how to track it. Pros and cons. Keep it simple.
```

## CLIENT COMMUNICATION (10 Prompts)

### 23. New Client Welcome Email
```
Write a welcome email for a new personal training client [NAME] starting on [DATE]. Include: what to expect in session 1, what to bring/wear, arrival time, pre-session nutrition tips, and my contact info for questions. Set an enthusiastic but professional tone.
```

### 24. Missed Session Follow-Up
```
Write a caring but professional message to [CLIENT NAME] who missed their session on [DATE] without notice. Express concern (not frustration), remind them of my cancellation policy, and offer to reschedule. Keep the door open without being a pushover.
```

### 25. Progress Celebration Message
```
Write an encouraging message to [CLIENT NAME] celebrating their progress: [SPECIFIC ACHIEVEMENT - e.g., lost 10 lbs, first pull-up, consistent for 8 weeks]. Be genuine, highlight their hard work, and set up the next milestone to keep momentum.
```

### 26. Motivational Check-In (Struggling Client)
```
Write a supportive message to [CLIENT NAME] who has been struggling with [MOTIVATION/CONSISTENCY/RESULTS]. Acknowledge the difficulty without enabling excuses. Offer a specific suggestion to get back on track. Empathetic but forward-focused.
```

### 27. Program Update Email
```
Write an email to [CLIENT NAME] explaining their updated program. Changes: [DESCRIBE CHANGES]. Reason for changes: [EXPLAIN]. What to expect: [HARDER/DIFFERENT/MORE VOLUME]. Include encouragement that they're ready for this progression.
```

### 28. Payment Reminder
```
Write a friendly payment reminder to [CLIENT NAME] whose payment of $[AMOUNT] is [OVERDUE/DUE]. Keep it professional and not awkward. Include payment options and deadline. Maintain the relationship while being clear about expectations.
```

### 29. Re-Engagement Message (Inactive Client)
```
Write a message to [CLIENT NAME] who hasn't trained in [X] weeks/months. Don't guilt-trip. Express that I noticed they've been away, the door is always open, and offer a low-commitment way to restart (e.g., one session to reassess). Warm and no-pressure.
```

### 30. Referral Request
```
Write a message to [CLIENT NAME] who has been getting great results asking if they know anyone who might benefit from training. Make it a natural ask, not pushy. Mention my referral incentive if applicable: [INCENTIVE]. Thank them regardless.
```

### 31. Holiday/Vacation Message
```
Write a message to my clients before [HOLIDAY/MY VACATION]. Include: schedule changes, a simple workout they can do on their own, nutrition tips for [HOLIDAY EATING/TRAVEL], and encouragement to enjoy themselves without guilt. Duration of closure: [DATES].
```

### 32. Client Offboarding Message
```
Write a professional farewell message to [CLIENT NAME] who is ending their training (for [REASON: moving/financial/achieved goals]). Express gratitude, summarize their journey, provide final tips for continuing independently, and leave the door open for future.
```

## MARKETING & SOCIAL MEDIA (10 Prompts)

### 33. Trainer Bio
```
Write a professional bio for a personal trainer. Name: [NAME]. Certifications: [LIST]. Specialties: [LIST]. Years experience: [X]. Personal story: [BRIEF BACKGROUND - why you became a trainer]. Ideal client: [DESCRIBE]. Tone: [MOTIVATING/APPROACHABLE/PROFESSIONAL]. 150 words max.
```

### 34. Instagram Transformation Post
```
Write an Instagram post featuring [CLIENT NAME]'s transformation (with their permission). Results: [BEFORE/AFTER STATS]. Time frame: [X] weeks/months. Highlight: their commitment, key changes made, and how they feel now. Include relevant hashtags and CTA to DM for info.
```

### 35. Educational Carousel Content
```
Write 6 slides for an Instagram carousel about [TOPIC: e.g., "5 Reasons You're Not Building Muscle" / "Beginner Gym Mistakes" / "How to Actually Lose Fat"]. Slide 1: hook. Slides 2-5: actionable points. Slide 6: CTA. Keep each slide under 30 words.
```

### 36. Myth-Busting Post
```
Write a social media post busting this fitness myth: "[MYTH - e.g., Lifting makes women bulky / Cardio is the best way to lose fat / You need supplements to see results]". Explain the truth simply. Position as educational, not preachy. Include engagement question.
```

### 37. Workout Reel Script
```
Write a script for a 30-60 second Instagram Reel demonstrating [EXERCISE/WORKOUT]. Include: hook (first 3 seconds), exercise breakdown, common mistakes to avoid, who this is for. Add text overlay suggestions and trending audio style recommendation.
```

### 38. Testimonial Post
```
Turn this client testimonial into an engaging post: "[TESTIMONIAL TEXT]" - [CLIENT NAME]. Add context about their journey, express gratitude, make it relatable to potential clients who might feel the same way. Include CTA.
```

### 39. Service/Package Promotion
```
Write a promotional post for my [SERVICE: e.g., "6-Week Transformation Program" / "Online Coaching" / "Small Group Training"]. Include: what's included, who it's for, price/value, urgency element, and clear CTA. Make it compelling without being salesy.
```

### 40. Weekly Fitness Tip Post
```
Write a quick, valuable fitness tip post about [TOPIC]. Make it immediately actionable - something they can implement today. Keep it under 100 words. End with "Save this for later" or engagement prompt.
```

### 41. Q&A Prompt Post
```
Write an Instagram Story Q&A prompt asking followers to submit questions about [FITNESS/NUTRITION/MY TRAINING]. Make it inviting and specific enough to get good questions. Include 3 example questions to prime the pump.
```

### 42. Personal Brand Post
```
Write a personal post sharing [TOPIC: your fitness journey / why you became a trainer / a struggle you overcame / behind-the-scenes of your day]. Be vulnerable and authentic. Connect it back to how you help clients. Build know-like-trust.
```

## BUSINESS & OPERATIONS (8 Prompts)

### 43. Consultation Call Script
```
Create a consultation call script for a potential new client. Include: rapport building (2 min), understanding their goals and history (5 min), explaining my services (3 min), handling common objections, and closing/next steps. Total: 15 minutes. Conversational, not robotic.
```

### 44. Training Agreement
```
Draft a personal training agreement/contract including: services provided, session rates ($[AMOUNT]), payment terms, cancellation policy ([X] hours notice required), liability waiver language, and term length. Keep it professional but readable. Add signature lines.
```

### 45. Session Package Options
```
Help me create 3 training package options for clients. My session rate: $[AMOUNT]. Create: a starter package, a results package, and a premium/transformation package. Include: number of sessions, price, savings percentage, what's included, and who each is best for.
```

### 46. Cancellation Policy Explanation
```
Write a clear explanation of my cancellation policy to include in my welcome packet. Policy: [DESCRIBE - e.g., 24 hours notice required, late cancel = charged, no-show = charged]. Explain the reasoning respectfully. Make it firm but fair.
```

### 47. Price Increase Announcement
```
Write an email announcing a price increase to my existing clients. Current rate: $[OLD]. New rate: $[NEW]. Effective date: [DATE]. Option to lock in current rate: [YES/NO, DETAILS]. Express gratitude, justify the value, maintain relationships.
```

### 48. Online Coaching Onboarding
```
Create an onboarding checklist and welcome document for my new online coaching client. Include: what to expect, how to use my app/platform, communication expectations, check-in schedule, how to log workouts, and how to reach me. Set clear expectations.
```

### 49. Goal Setting Session Questions
```
Create a list of questions for a goal-setting session with a new client. Cover: specific goals, timeline, past fitness history, current lifestyle, potential obstacles, support system, motivation drivers, and how they'll measure success. Deep but not overwhelming.
```

### 50. Client Intake Form
```
Create a comprehensive client intake form for new personal training clients. Include: contact info, health history, injury history, current fitness level, goals, schedule availability, dietary preferences/restrictions, and emergency contact. Format for easy digital or print use.
```

## BONUS PROMPTS (5 Extra)

### 51. Exercise Instruction
```
Write clear instructions for performing [EXERCISE NAME] including: muscles worked, proper setup, step-by-step execution, breathing cues, common mistakes, and variations (easier/harder). Format for a client handout.
```

### 52. Form Correction Message
```
Write a tactful message to [CLIENT NAME] about correcting their form on [EXERCISE]. Describe what you noticed, why it matters (injury risk/effectiveness), and cue them on the fix. Be encouraging, not critical.
```

### 53. At-Home Equipment Guide
```
Create a home gym equipment guide for a client with a $[BUDGET] budget. Recommend: essential items first, nice-to-have second. Include specific products/types, what exercises each enables, and space requirements. Prioritize by value.
```

### 54. Post-Baby Return to Fitness
```
Create guidelines for a client [X] weeks/months postpartum returning to exercise. Include: clearance requirements, what to avoid, how to progress safely, core/pelvic floor considerations, and realistic expectations. Note: always defer to their doctor.
```

### 55. Race/Event Prep Timeline
```
Create a training timeline for a client preparing for [EVENT: 5K/marathon/obstacle race/competition] in [X] weeks. Current fitness level: [DESCRIBE]. Include: weekly focus areas, key workouts, taper strategy, and event day tips.
```
